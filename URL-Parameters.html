Parameter Description Examples
board Board number, max. 15 characters board=14
dealer Dealer, one character out of N, S, E or W dealer=E
vul Vulnerability, one of NS, EW, All or None vul=All
north, south, east, west Hand for each of the positions. Order of suits: Spade-Hearts-Diamonds-Clubs.
Cards for each suit are separated by a dot (.)		 west=KQJ..A9764.JT432
contract The played contract contract=4SxN
declarer Declarer, one of N, S, E or W declarer=W
title Title for display above the diagram, may contain HTML tags title=<b>Championship on July, 4th<b>
analyse Defines whether analysis should be done automatically analyse=true
dd Double Dummy analysis. A string of 20 characters dd=334234444422222323a3
optimumscore Optimum score for a single board optimimumscore=4SN+2
leadcard Played card, 2 characters, first is card, second is suit leadcard=QS
event, eventid Name of the event event=Championship
lin A string of characters that represents a played board as available from BBO lin=pn|Bodensee20,Anjaaa,rollhase,AnT07|st||md|3S8KH258D248TQC...c|DT|pc|H7|pc|D7|pc|DQ|pc|SQ|
club Name of the club club=Bridgeclub XXX
pair_number Pair number for a single board pair_number=402
direction
compare
file Names a URL for a file to be loaded for analysis. Can be any of format .pbn, .lin, .dlm
Note:
If the pbn file for retrieval is on a different domain then that domain must have a CORS header in place by setting "Access-Control-Allow-Origin" to either to * (all domains can retrieve pbn files) or to a specific domain 		file=https://www.example.com/20250916.pbn
xml Names a URL for an xml file. It must be used together with a "file" parameter that loads the corresponding pbn data.
Note:
The xml file can be generated by converting a downloaded csv file from BBOs result page using the BBO Extractor extension. See documentation here: https://mirgo2.co.uk/bboextractor/ 		xml=https://www.example.com/test.xml&file=https://www.example.com/test.pbn
sessid
msec Section number for multiple section events msec=2
display One of allpairs, personal or board display=allpairs
analysis Request is from BridgeWebs. This means that "Results Analysis" button will be displayed.
If any 3rd party site sets this parameter the button will be displayed but won't display any data.
debug Debugging the application debug=true
jsonline
lang Language code for displayed text. lang=de
nav Hide or show top navigation area nav=0
